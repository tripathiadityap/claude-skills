# Podcast episode package

Load `creator-profile` first for the show name, its formats, its promise and where it publishes. This skill handles one episode end to end.

## Inputs (ask only if missing)

Episode number or title, guest name and a one-line who-they-are, transcript or detailed notes, and any moments the host already loves. Never invent guest quotes. Without a transcript, work from what is given and mark quotes `[pull from transcript]`.

## Workflow

1. **Find the spine.** The single biggest turning point or tension, plus 3 to 5 supporting moments. Each must be emotionally complete or practically useful.
2. **Canonical package** (everything routes back here):
   - 3 title options. Specific, human. No clickbait the episode cannot cash.
   - Description, 120 to 180 words: who, the tension, what the listener walks away with.
   - Chapters, if a timed transcript is given.
   - Show-notes footer with the platforms from the profile.
3. **Distribution set:**
   1. **Clip picks (2 to 4):** transcript anchor or timestamp, why it works (story, tension or practical insight), on-screen hook text, YouTube title and description.
   2. **Short picks (1 to 3):** discovery moments under 45 seconds that route back to the full episode.
   3. **Newsletter essay angle:** working title plus a 3 to 5 bullet outline. Hand off to `newsletter-essay` for the full piece.
   4. **One LinkedIn post and one X post or thread** built on the episode's strongest thesis, following `linkedin-x-posts`.
4. **Tag every derivative with its source episode** (number and title) so it can be logged in an episode library.

## Editorial standard

- Keep uncertainty, trade-offs, awkward transitions and hard-won clarity.
- No generic motivation, no contextless viral clips. A clip that only works out of context is a no.
- Never invent numbers.

## Output order

Titles, Description, Chapters, Show Notes, Clips, Shorts, Essay Angle, LinkedIn Post, X Post or Thread. If the profile lists a Notion episode library, add the package to that episode's entry.
